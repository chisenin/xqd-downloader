# 架构与代码结构

## 分层

```
┌─────────────────────────────────────────────────────────┐
│  ui.html            前端单页（原生 JS，无框架）           │
│  标签切换 → 营列表 → 课程列表（勾选框 + 单节/批量下载）  │
└──────────────────────────┬──────────────────────────────┘
                           │ JSON HTTP API
┌──────────────────────────┴──────────────────────────────┐
│  xqd_server.py      本地 HTTP 服务（Python 标准库）       │
│  · GET  /api/state              状态                    │
│  · GET  /api/camps?tab=…        某标签下的营              │
│  · GET  /api/courses?camp=…     某营课表                 │
│  · GET  /api/files?camp=…       已下载文件                │
│  · POST /api/sweep   {camp}      逐节绑定 fileId          │
│  · POST /api/download {camp,items} 批量下载              │
│  · POST /api/settings {out}      改输出目录               │
│  · POST /api/open_folder {path}  打开目录                 │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────┴──────────────────────────────┐
│  xqd_app.py         业务动作层                          │
│  标签→营→课表→fileId→链接→下载                            │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────┴──────────────────────────────┐
│  xqd.py             底层采集层                          │
│  ADB 封装 / 页面识别 / DOM 解析 / 清单读取               │
└─────────────────────────────────────────────────────────┘
```

**依赖方向严格单向向下**，上层可 import 下层，下层不感知上层。

## xqd_app.py —— 业务动作层

### 持久化（`state/` 目录）
| 文件 | 结构 | 含义 |
|---|---|---|
| `names.json` | `{fileId: {name, when, camp}}` | 课名 ↔ fileId 映射 |
| `links.json` | `{fileId: {url, ts, camp}}` | fileId → 播放链接 |
| `catalog.json` | `{camp: [{title, when, index}]}` | 各营课表 |

### 函数
| 函数 | 职责 |
|---|---|
| `select_tab(tab)` | 切标签 |
| `_parse_camps(xml)` | 解析营卡片 → `[{name, badge}]`（去重保序） |
| `list_camps(tab, scroll)` | 滚到底列出某标签下所有营 |
| `_badge_count/_badge_type(badge)` | 解析角标「正式营•共70课」 |
| `_cards_from_xml(xml)` | 课程卡片解析（文档顺序配对） |
| `camp_catalog(camp)` | 某营完整课表 |
| `play_and_capture(target, before, timeout)` | 点「去学习」→ 轮询清单刷新 → 返回 fileId 列表 |
| `sweep_camp(camp, progress)` | 逐节播放，写入 names/links |
| `split_dir_query(url)` | 拆 URL → `(目录, 文件名, 查询串)`，保留三层目录 |
| `query_without(query, drop)` | 去掉指定查询参数（如 `encdomain`） |
| `http_get(url, timeout)` | HTTP GET，**不走系统代理**，跳过 TLS 校验 |
| `classify_manifest(url)` | 判清单类型：`master` / `media` / `drm` |
| `find_plain_twin(drm_text, url)` | 找同源明文孪生（**带时长校验**） |
| `_pick_variant(text, dir, q)` | 从 master 提取子清单列表 |
| `safe_name(s)` | 合法化 Windows 文件名（保留全角冒号） |
| `_ff_out_path(out)` | ffmpeg 临时输出路径（必须 `.mp4` 结尾） |
| `download(url, out, progress)` | 下载一节课，返回 `(成功, 说明, 进度%)` |
| `probe_alive(url)` | 链接是否仍有效 |
| `collect_links_from_cache()` | 从远端清单收集链接 |

## xqd_server.py —— 服务层

- `ThreadingHTTPServer` + `BaseHTTPRequestHandler`，仅标准库。
- **ADB 操作必须串行**：所有涉及 UI 的动作用 `ADB_LOCK` 保护。
  下载是纯网络/文件操作，可并发。
- 后台任务用 `threading.Thread(daemon=True)`，每个任务包一层
  `_run_*_guarded` 异常保护 —— **任何异常都要把任务标记为 error，不能静默挂起**。
- 任务对象字段：`id / kind / title / state / progress / current / ok / fail / log[]`。
- `STATE['tasks']` 只保留最近 40 条，前端只取 12 条。

### ⚠️ 服务启动方式
必须用**后台任务**启动，不能用 `&` 后台化（会随 shell 结束被杀掉）：
```
python -u xqd_server.py --port 8765 --out "D:/user/chisenin/Videos"
```

### ⚠️ 测试注意
本机 curl 会走系统代理，**必须加 `--noproxy '*'`**：
```
curl -sS --noproxy '*' http://127.0.0.1:8765/api/state
```

## ui.html —— 前端

原生 JS，无框架，无构建步骤。服务端直接把 `ui.html` 作为 `/` 返回。

- 顶栏：品牌名 + 四个筛选标签 + 输出目录显示 + 打开目录按钮
- 左栏（330px）：营列表卡片
- 右栏：课程表格，每行 = `[勾选框] 课名 | 日期 | [下载]`
- 课程表上方显示**营名** + **批量下载按钮**
- 底部任务面板：进度条 + 日志

## archive/probes/ —— 一次性探测脚本（已归档）

50 个脚本，是**探索过程的化石记录**，不是生产代码：
`q_*.py`（页面结构探测）、`_probe*.py`（DOM/清单验证）、
`_test_dl.py`（下载验证）、`_rebuild_links.py`（链接重建）。

> 这些脚本的价值在于**记录当时的探测方法**。
> 若需要重复某个探测，先查 `docs/01-已验证事实.md`，
> 确认结论没有记录过才写新脚本。
