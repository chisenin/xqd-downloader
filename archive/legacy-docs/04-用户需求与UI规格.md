# 用户需求与操作约定

## 背景与约束

用户是教师。

- **网络极不稳定、流量昂贵** → 尽量少请求、别重复下载。
- **教学大屏磁盘小** → 导出后临时转移，用完删除。
- 设备：桌面级 PC + MuMu 模拟器（桥接模式，ADB 本地直连）。

## 核心目标

把「兴趣岛」App 中**已下载或可播放**的课程视频批量导出为**通用 MP4**，
临时转移到教学大屏，用后删除。

## 明确排除的做法

- ❌ 投屏 / HDMI
- ❌ 录屏（ADB 录屏黑屏；MuMu 录屏耗时且耗流量）
- ❌ App 内逐课手工点击下载

## 需要的范围

- 只要**自己付费订阅**的课程 → **正式营** 和 **体验营**。
- 其它标签（全部 / 轻课）是 App 强推内容，**可以一并列出**，但不是必需。
- 「轻课」已确认是**空标签**，直接显示空列表即可，不要反复探测。

## UI 需求（用户明确描述）

1. **标签切换** —— 与 App 的「学习」页标签一致：全部 / 正式营 / 体验营 / 轻课。
2. 点击标签 → 列出该标签下的**大课程（营）列表**。
3. 点击某个大课程 → 进入该营的**全部课程列表**：
   - 列表**上方显示营名**（大课程名）
   - 营名**旁边加一个「批量下载」按钮**
   - 下方是具体课程列表
4. 每节课程一行：
   - **前面**加一个**选择框**（勾选 = 参与批量下载）
   - **后面**跟一个**下载按钮**（单击 = 单独下载这一节）

> 现状：`ui.html` 已实现以上全部交互。

## 保存结构（用户指定）

```
D:\user\chisenin\Videos\        ← 总目录
└── 引气归源太极营\              ← 营名子目录
    └── 先导课：解谜自然之道.mp4  ← 正式课名.mp4
```

- 全角冒号 `：` 保留，这是用户要的命名格式。
- 输出目录可在 UI 顶栏查看，另有「打开目录」按钮。
