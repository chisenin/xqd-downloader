## 兴趣岛课程 · 教学现场离线播放方案

- 背景：用户已购兴趣岛课程，App 缓存为**加密切片**；`adb screenrecord` 黑屏（DRM secure surface），MuMu 自带录屏可用但耗时；教学现场外网极不稳、流量贵、手机与大屏存储都小，需把课程放到教学大屏离线播放，用完即删。

- 明确边界：不提供密钥提取 / 逆向 / 抓包解密。《著作权法》（2020 修正）第 24 条第 1 款第（六）项为学校课堂教学播放或少量复制已发表作品留有合理使用空间；长期方案建议向官方（班主任 / 400-8328080 / service@qlchat.com）申请课堂离线资源授权。

## 兴趣岛课程导出 —— 突破：明文孪生模板（2026-11-06 晚）

> 上面的「不导出」结论已被本轮实测推翻。以下为实测可用路径。

- **核心突破（无需解密 DRM）**：腾讯云转码模板在同一个课程目录下会同时存在多套产物：
  - `adp.1440285.m3u8` / `video_1440285_*.m3u8` → DRM 版（含 `EXT-X-KEY`，腾讯云 SimpleAES）
  - `v.f1440283.m3u8` → ★ **同内容的未加密孪生模板**（清单里没有 EXT-X-KEY）
  - 而 `sign` 只绑定「目录 + t」，**不绑定文件名** ⇒ 用课程自身的 sign 请求同目录的 `v.f1440283.m3u8` 即可拿到明文分片，完全不需要解密。
  - 实测：第七课（DRM，1440285）→ `v.f1440283.m3u8` → 分片首字节 `47 40 11 10`，188 对齐同步字节 1322/1322 全中 → ffmpeg 直连导出 78.3MB / 21分34秒 / 1280x720 / 25fps / H.264+AAC，播放正常。
- **URL 结构**：`https://video2.qianliao.net/43a5a542vodtranscq1500020547/<8hex><业务fileId>/<文件名>?<encdomain=cmv1&>sign=<md5>&t=<hex>`
  - 目录段 = `https://video2.qianliao.net/<appId>/<8hex><业务fileId>/`（sign 绑定这一层）
  - appId = 1500020547
  - **URL 里的 `t` 不是标准 Unix 时钟**：实测比服务器 Date 头快约 4.8 小时 ⇒ **不能用时间戳判断签名过期，必须 HTTP 实探（200/403）**。
  - `sign` 与 `t` 强绑定，改任一都 403，不能自造签名。
- **链接来源**：App 每播放/下载一节课，就把该课完整 URL 写进隐藏文件 `/sdcard/Android/data/com.qlchat.xingqudao/files/PlayerCache/txcache/.<md5>.hls` ⇒ 「让 App 播一遍」= 拿到签名链接。
- **加密结构（已定性）**：腾讯云 SimpleAES = AES-128-CBC + PKCS#7。判据：密文长度 `375440 = 188×1997 + 4`、`248736 = 188×1323 + 12` ⇒ 明文是 188 对齐的 TS 包 + 4/12 字节填充。license 端点返回的 16 字节与 App 缓存 `tp_dp_file` 密钥一致，但与 CBC 链式判据不符（已排除所有标准变体与 234 组派生式）⇒ 是自研变体，**有孪生模板就无需解密**。
- **交付物**：`export_courses.py`（`list` / `pull` / `download` / `play` / `sweep`）
  - `download` 自动：HTTP 实探选有效签名 → DRM 课自动探测明文孪生模板 → ffmpeg `-c copy` 转封装 MP4
  - `play` / `sweep`：在 App 内自动播放课程刷新签名（sweep 支持滚动遍历课表）
  - 课程名来自 `qlChatCourses.db` 的 `video_download_task` 表（需 root）
- **App 自动化要点**（MuMu 900×1600）：
  - 启动入口是 `.SplashActivity`（`ui.activity.MainActivity` 不存在），用 `monkey -p <pkg> -c android.intent.category.LAUNCHER 1` 最稳
  - 课表条目 resource-id = `nameTv`；营卡片 id = `title`；营详情页课程条目 id = `tv_title`（在「每日计划」标题下方）
  - 底部 tab 文字节点 y≈1552，点击有效；播放器识别特征 = `tab_item_text` + `nameTv`（`superPlayerView` 有时不在 dump 里）
  - 营详情页要先下滚一屏才露出当天课程条目
  - 加固壳隐藏了 Activity 列表，无法用深链；`dumpsys package` 只暴露 `.SplashActivity` / `.KwaiRouterActivity`
- **工具环境坑**：Git Bash 下 `adb pull` 路径会被转换 → 需 `MSYS_NO_PATHCONV=1`；Python 用 `C:/Users/chise/.workbuddy/binaries/python/versions/3.13.12/python`；ffmpeg 在 PATH 中。

## 兴趣岛课程导出 —— UI 工具化 + 工程化归档（2026-11-07 凌晨）

- **UI 工具建成**：标签切换 → 营列表 → 点营进入课表（顶部显示营名 + 批量下载按钮）→ 每行「勾选框 + 下载按钮」。四层结构：`xqd.py`（底层采集）/`xqd_app.py`（业务）/`xqd_server.py`（本地 HTTP 服务，仅标准库）/`ui.html`（前端原生 JS）。ADB 操作走串行锁，下载可并发。
- **导航路径定案（用户指认）**：首页 →「学习」→ 点大课程名 → 点红框「课程」图标 → WebView 课程列表 →「去学习」→ 播放器。播放器**按一次 BACK 即回列表且滚动位置保留**。
- **课名来源纠正**：课程列表页**一次 dump 就含整营全部课名**（屏幕外节点 bounds 为 0 但文本可读），按 DOM 文档顺序配对课名/日期/「去学习」—— 不再靠播放反推。
- **fileId 绑定**：播放后用清单 mtime 差分定位，0.35s 轮询，约 0.7 秒/节，70 节约 1 分钟。
- **DRM 孪生命名规律**：`voddrm.token.<JWT>.video_1440285_0.m3u8` → 明文孪生 `v.f1440285.m3u8`（编号一致）；**必须校验总时长**（实测 782.4s / 1214.0s 精确吻合），同目录还有 2.8h 的无关视频，不校验会下错内容。68 个课程目录**0 个含多课**，不串课。
- **master 课不能走孪生**（实测孪生时长 10095s 与课程不符）；master 选码率按**短边** min(w,h) 判断，这批课多竖屏（480x852 / 720x1280）。
- **踩坑**：ffmpeg 临时文件必须 `.mp4` 结尾（`.part` 会 "Error initializing the muxer"）；目录拆分用 `rsplit('/',2)` 保留三层；请求孪生须去掉 `encdomain=cmv1` 否则 403；`t` 偏移服务器时钟 ~4.8h 须 HTTP 实探；服务须用后台任务方式启动（`&` 会随 shell 退出被杀）；curl 测接口须 `--noproxy '*'`；模块内误写 `A.http_get` 导致 NameError 静默卡死。
- **本轮收尾**：全部所得资产梳理成 `docs/` 五份文档（01 已验证事实 / 02 架构 / 03 踩坑 / 04 需求 / 05 待办）+ README，50 个一次性探测脚本归档到 `archive/probes/`，`.gitignore` 排除 1.9G cache-analysis 等产物，**已建 git 仓库并提交**（commit 6144f68）。
