# 踩坑与修复记录

> 每一条都是**实际浪费过时间**的坑。修好之后不要再犯。

---

## A. 方法论层面的坑（最贵的）

### A1. 靠播放反推课名 —— 绕了远路
- **错误做法**：点开一节课 → 播放 → 观察 → 猜这是哪一节 → 记录。
- **事实**：进入课程列表页（WebView）时，**全部课名一次性就在 DOM 里**。
- **正确做法**：先一次性采集整营课表（课名+日期），再逐节播放绑定 fileId。
- **用户原话**：「进入时已经获得课程名，为何还需反复尝试。」

### A2. 反复探测同一个已知结论
- **错误做法**：轻课标签已确认是空的，还一次次去探测。
- **用户原话**：「已经得到空标签，就代表它里面为空，直接显示空列表即可。」
- **对策**：所有结论写进 `docs/01-已验证事实.md`，探测前先查。
  **文档里有的结论，不要重新验证。**

### A3. 反复尝试「返回」
- 播放器**一次 BACK 就回课程列表页**，且滚动位置保留。
- 不要写「连点 N 次返回 + 每次校验页面」的循环。

### A4. 把直播回放页当成群聊页
- 页面含 `messageContent` 被判为 `chat`。
- 实际是**直播回放页**，右下角「更多 → 目录」就是原生听课列表。

### A5. 页面识别特征不足导致误操作
- 「学习」页原用"有营卡片"判定 → 停在空的「轻课」标签时判定失败 → 误退。
- **正确**：用筛选标签组判定（`tv_title` + 4 个标签命中 ≥3）。

## C. 下载链路坑

| # | 问题 | 症状 | 修复 |
|---|---|---|---|
| C1 | ffmpeg 临时文件用 `.part` | `Error initializing the muxer` | 必须以 `.mp4` 结尾：`.part.mp4` |
| C2 | 目录拆分错误 | URL 拼出来 404 | `rsplit('/', 2)` 保留 `host/appId/<8hex><biz>/` 三层 |
| C3 | 孪生请求带 `encdomain` | 403 | 请求明文孪生时**去掉** `encdomain=cmv1` |
| C4 | 用本地时间判断签名有效性 | 出现负值、误判 | `t` 偏移服务器时钟 ~4.8h，用 **HTTP 200/403 实探** |
| C5 | 明文课也用孪生 | 下了 2.8 小时的无关视频 | 孪生**只用于 DRM 课**；master/media 直连 |
| C6 | 孪生可能串课 | 同目录有别的视频 | **必须校验总时长**（容差 `max(1, want*0.005)`） |
| C7 | 全角冒号被替换 | 文件名不对 | ffmpeg 只把 ASCII `:` 当分隔符，**保留全角 `：`** |
| C8 | 服务未重启就跑新代码 | 修了 bug 但行为不变 | 改完 `xqd_app.py` **必须重启服务** |

## D. 服务与工程坑

| # | 问题 | 症状 | 修复 |
|---|---|---|---|
| D1 | `&` 后台启动服务 | shell 结束服务被杀 | 用**后台任务**方式启动 |
| D2 | curl 走系统代理 | 127.0.0.1 请求超时 | 加 `--noproxy '*'` |
| D3 | 内部写 `A.http_get` | `NameError` 静默卡死 | 模块内直接用 `http_get`；**后台线程必须包异常保护** |
| D4 | 任务进度显示 0% 不动 | 看起来像卡死 | 加"准备中"状态 + 每项结束更新进度 |
| D5 | `%dx%s` 格式化串混用 | `TypeError` | 统一 `%sx%s` / `%dx%d` |
| D6 | `ls --full-time` 正则解析反复出错 | mtime 取不到 | 改用 `split()` 按字段索引读 |
| D7 | 任务静默挂起无日志 | 无法定位 | `_run_*_guarded` 捕获异常 → `state='error'` + `last_error` |
