# 兴趣岛视频下载器（Avalonia 版 GUI 说明）

> 本文描述**当前正式界面**：`xqd-avalonia/`（Avalonia 11 + .NET 8，v1.7.1）。
> WPF 版（`Xqd.Gui`）与 Python/PySide6 版均已从 master 删除，
> 只保留在 `csharp-wpf` 分支与 git 历史里。
> 单表规格的原始设计稿见 [`docs/13-GUI单表合并规格.md`](13-GUI单表合并规格.md)，
> 架构改版与 UI 重做的来龙去脉见 [`docs/14-架构改版v1.7.0.md`](14-架构改版v1.7.0.md)。

单文件桌面工具，把**你有权访问的**已购课程 / 体验营 / 公开课导出成通用 MP4。
下载内核在 `Xqd.Core`，界面只负责编排与展示。

产物：`xqd-downloader-v<版本>.exe`（自包含单文件，约 44 MB，
目标机不需要 .NET、不需要 Python，Windows 10/11 x64 双击即用）。

---

## 一、启动

**日常使用**：双击 `xqd-downloader-v1.7.1.exe`。

启动后做三件事（全自动，不弹窗打断）：

1. 读本机缓存授权 → 有就**不启动模拟器**，直接拉营列表；
2. 没有缓存才提示「尚未授权」，需要用户点「重新授权」；
3. 载入下载历史，恢复「上次下载」列表与可续传进度。

**排障/运维入口**（无界面，控制台输出）：

| 参数 | 作用 |
|---|---|
| `--version` | 打印版本（`1.7.1`） |
| `--check` | 环境体检：配置目录 / 下载目录 / ffmpeg / ffprobe / MuMu / adb |
| `--authcheck` | 授权诊断：MuMuManager 实际路径 + 实例 0~7 各自是否在跑、是否有登录态、最终选哪台（不打印任何 cookie 值） |
| `--install-deps` | 静默下载 ffmpeg/ffprobe 到 `~/.xqd_tool/ffmpeg/bin` |
| `--waitauth [秒]` | 只开「等待模拟器登录」小窗、不加载主界面；读到登录态自动关窗退出（默认上限 180 秒） |

### 顶栏（DockPanel 停靠）

声明顺序即空间分配顺序，**窗口三键最先以右侧停靠声明**，所以内容再多也推不出它们：

1. 右：`最小化 / 最大化(还原) / 关闭` —— `Controls/WindowButton`，44×34 矢量自绘
   （— / □ / 双框 / ✕），关闭悬停红底，其余悬停白色蒙层；最大化后自动换成「还原」图标。
2. 右：授权状态字（`未授权` / `已授权（本机缓存）` / `已授权（模拟器）`，超长省略）
   → 「重新授权」→「环境检查」。
3. 左：品牌区（`岛` 圆角块 + 名称 + 副标题）——**单击开「关于」，拖动移窗，双击最大化**。
4. 左：「下载目录」+ 输入框（230 宽，圆角）+「浏览…」——**回车或失焦即生效**。

### 左侧「我的课程」

- 标题右显示营数徽章；「刷新」重新拉营列表。
- 搜索框按**营名**过滤（不区分大小写），过滤结果按分组重建。
- 「全选」三态：全未选 / 部分选 / 全选；点一次即二态化，再点反向。
- 分组固定两组：**已购课程**（`skuType != OPEN_COURSE`）与**公开课**（`OPEN_COURSE`）；
  同名营第 2 个起显示 `(2)`。
- **勾选即并入**右侧同一张表：首次勾选会拉该营课表（缓存于本次会话），
  已勾选的营取消勾选会把它的行摘掉。
- 每行右侧徽章显示该营节数；行底提示「共 N 个营，已勾选 K 个」。

### 右侧「下载清单」

两条工具行 + 表格 + 汇总条：

| 行 | 内容 |
|---|---|
| 第 1 行 | 标题「下载清单」+ 跑马灯（200 宽，显示当前正在下的课名）+ 暂停 / 取消 / **开始下载**（主按钮） |
| 第 2 行 | 5 个胶囊筛选（全部 / 待下载 / 下载中 / 已完成 / 失败）+ 画质下拉（最高画质 / 1080P / 720P）+ 重新扫描 + 重置记录 |
| 表头 | 状态 80 · 课程（自适应，最小 110）· 所属营 96 · 时长 56 · 大小 88 · 速度 68 · 剩余 60 · 进度 108 |
| 汇总条 | `共 N 节 · 待下载 X · 进行中 Y · 已完成 Z · 失败 W · 历史合计 …` + 右侧 `预计还需 …` |

★ **所属营列自动隐藏**：表里只有一个营时整列（含表头）收起，省出的宽度给「课程」；
多营合并才显示。列宽由 `UpdateTitleWidth()` 按 `LstRows.Bounds.Width` 实时算，
`Math.Max(110, 可用 − 固定列 − 26)`，因此 1100 / 1180 / 最大化三种宽度都不溢出。

★ 表头与数据行**必须同一套列宽**：表头绑定写 `{Binding $parent[Window].TitleWidth}`。
绑到 DataContext 会退化成「文字自适应」，视觉上像两列挤成一列（v1.7.1 修）。

### 「上次下载」卡

- 标题右侧 `N 条`（显示上限 60 条，历史文件最多存 500 条）。
- 四列：课名 / 所属营 / 状态词 / 大小；行高 24，最高 88，超出内部滚动。
- **双击行 → 打开该文件所在文件夹**。
- 已下完又被删掉的记录不会显示（`File.Exists` 过滤）；当前课表里已有的课也不重复出现。

### 「运行日志」卡

- 深底 `#1F2733` + 浅色等宽字；每行 `[HH:mm:ss] 内容`。
- 超 200,000 字符时截掉最旧的，保留最后 150,000（防止长时间挂着吃内存）。
- 「清空」只清显示，不动历史。

## 三、操作流程

1. **环境检查**（首次或换机器）：顶栏「环境检查」→ 看依赖列表 →
   缺 ffmpeg 点「自动安装 ffmpeg」（装到 `~/.xqd_tool/ffmpeg/bin`，
   不写系统 PATH、不需要管理员权限）→ 必要时「指定 MuMuManager…」。
2. **授权**：点「重新授权」。程序先找 MuMuManager（七级探测，见第七节），
   再扫实例 0~7，挑一台装着兴趣岛且有登录态的；成功后写 `cookie.txt` 复用。
3. **选营**：左侧勾选一个或多个营，课表逐节并入右侧；每节立刻按磁盘做一次「已存在」判定。
4. **选课/下载范围**（`开始下载` 的判定）：
   - **有选中行** → 只下这几行；
   - **没选行** → 下所有「待下载 + 失败/需重下」（`States.InDownloadScope`）；
     已完成、已存在、进行中的一律跳过；历史行永不参与。
5. **暂停 / 继续**：按钮二态。暂停时所有任务在**领下一个分片前**阻塞，
   分片保留；继续后回到各任务真实阶段。
6. **取消**：清空队列 + 取消在跑任务。已下分片保留，行标「已暂停」，
   下次再点「开始下载」即从断点续。
7. **失败重试**：右键「重试（清缓存后重下）」会先清该课分片缓存与历史状态，再排队；
   只想续传就别点重试，直接再点「开始下载」。
8. **验收**：状态变「已完成」= 分片齐 + 封装成功 + ffprobe 时长与课表标称误差在容差内
   （`max(3s, 1%)`）。

### 行交互

| 操作 | 结果 |
|---|---|
| 左键单击 | 选中（多选：Ctrl / Shift 走 ListBox 默认行为） |
| 左键双击（课表行） | 单独下载这一节 |
| 左键双击（历史行） | 打开成品所在文件夹 |
| 右键 | 菜单：下载该课 / 重试（清缓存后重下）/ 分隔 / 复制课名 / 打开所在文件夹 / 删除成品（移到 `_已删除`） |

★ 删除成品是**移到同目录的 `_已删除` 文件夹**，不是真删；同时清掉该条历史。
★ 删除/重置都有二次确认框；`_已删除` 里同名文件会被覆盖。

## 四、单表 8 列与状态词

### 列定义（常量在 `States.Col*`，界面与测试共用）

| 列 | 内容 | 来源 |
|---|---|---|
| 状态 | **胶囊**（圆角 9、三色底/字/描边） | `States.StatePills[word]` |
| 课程 | 纯课名，省略号截断 | `Lesson.Title` |
| 所属营 | 营名（单营时隐藏） | `Camp.Name` |
| 时长 | `mm:ss` / `h:mm:ss` | 课表 `duration` |
| 大小 | 下载中 `已下/总量`，完成显示成品大小，空闲 `—` | 进度回调 |
| 速度 | 字节速率（10 次/秒限流刷新；测不出显示 `—`） | `Job.Bmeter` |
| 剩余 | 计数时钟；完成后清成 `—`、改用日志里的用时 | 双速率计 |
| 进度 | 自绘进度条 + 百分比，颜色跟状态走 | `ProgressCell` |

### 状态词（`States.StateTexts`，单一事实来源）

```
解析中  下载中  封装中  校验中  排队中  已暂停  已完成  失败  已存在  需重下  待下载
```

| 词 | 含义 | 胶囊配色（底/字/描边） |
|---|---|---|
| 待下载 | 建行时的默认态，尚未入队 | `#EEF2F8` / `#5A6B80` / `#D3DAE6` |
| 排队中 | 已入队等网络槽位 | `#EEEDFE` / `#534AB7` / `#7F77DD` |
| 解析中 / 下载中 | 解析清单 / 下分片 | `#E6F1FB` / `#185FA5` / `#378ADD` |
| 封装中 / 校验中 / 已暂停 | 本地转封装 / ffprobe / 用户暂停 | `#FAEEDA` / `#854F0B` / `#BA7517` |
| 已完成 / 已存在 | 本次下完 / 磁盘上本来就有 | `#EAF3DE` / `#3B6D11` / `#97C459` |
| 失败 / 需重下 | 出错 / 有残件待重下 | `#FCEBEB` / `#A32D2D` / `#E24B4A` |

规则：

- **进行中三个阶段可自由切换**（`PhaseTexts` 白名单含全部阶段），
  不会出现「卡在解析中、其实早在下载」；
- **终态不被迟到信号覆盖**（已完成 / 失败 / 已存在 / 需重下）；
- 暂停时统一显示「已暂停」，继续后**回到真实阶段**，不笼统写「下载中」；
- 状态词是**唯一事实来源**：表内胶囊、进度条颜色、汇总统计、回归断言都读它。

## 五、下载调度与速率口径

### 并发

| 资源 | 上限 | 谁占用 |
|---|---|---|
| 网络槽位 | `States.MaxLessonWorkers = 3` | 处于「解析 / 下载」的课 |
| 分片并发 | `cfg.seg_workers`（默认 `States.SegmentWorkers = 12`） | 单节课内部 |
| 本地封装 | 引擎内串行（`Muxer.ConcatAndMux`），不发网络请求 | — |

入队即标「排队中」并清空大小/速度/剩余；`PumpQueue()` 只在 `_active < 3` 时取队首，
`_active == 0 && 队列空` 即 `FinishRun()`（解锁「开始下载」、写本批汇总）。

### 两种速率，别混用

| 速率计 | 喂什么 | 单位 | 用途 |
|---|---|---|---|
| `Job.Bmeter` | 已下**字节** | B/s → MB/s | 「速度」列；直链音频的 ETA |
| `Job.Meter` | 已下**内容时长** | 内容秒/秒（倍速） | 分片视频的 ETA |

- 直链音频（MP3/M4A/AAC）没有分片时长 → `Unit == "byte"`，退回字节口径；
- 分片视频 → `Unit == "dur"`，ETA 用内容速率；
- **进度按内容时长占比**，不按字节占比（总字节是抽样外推值，按字节算会偏）；
- **总字节 = 跨清单等距抽 12 片外推**（不是取前 3 片；直播课开头码率高，取前几片会高估 ~37%）；
  抽样片直接落盘复用，不额外浪费请求。

### 时间格式

`天:时:分:秒`，按需省略前导零段：`45` / `1:30` / `1:01:01` / `1:02:03:04`；
最高位不补零，其余段两位。

## 六、筛选、画质、扫描与重置

### 视图筛选（只影响显示，**不影响下载范围**）

| 胶囊 | 含哪些状态 |
|---|---|
| 全部 | 全部（历史行也只在这里出现） |
| 待下载 | 非进行中、非完成/已存在、非失败 |
| 下载中 | 下载中 / 解析中 / 封装中 / 校验中 / 排队中 / 已暂停 |
| 已完成 | 已完成 + 已存在 |
| 失败 | 失败 + 需重下 |

切换视图只重建 `_view`（界面集合），`_rows`（全量）不动，所以筛选状态下点「开始下载」
仍然按全量判定范围。

### 画质

`最高画质（max，默认） / 1080P / 720P`；切换即写入 `config.json` 并记一行日志。
选路按**短边** `min(w,h)` 排序（这批课多为竖屏，看高度会误选最差一路）：
`max` 取短边最大那一路；指定分辨率取「短边 ≥ 该值的最小一路」，
没有达标档就退回最高一路。

### 重新扫描

按磁盘现状重判每个课表行：命中完整成品 → 「已存在 / 100% / 大小 / 成品路径」，
其余不动。用于手拷文件进目录、或在别处下过之后同步状态。
判据见第七节「已存在判定」。

### 重置记录

确认后清空 `history.json` 与「上次下载」列表，并把课表行状态复位为「待下载」。
**不删任何成品文件**；重置后不会自动重扫，需要时点「重新扫描」按磁盘现状补回「已存在」。

## 七、已存在判定 / 历史 / 续传

### 已存在判定（`Dedupe/ExistingChecker`）

按顺序，缺一不算「已存在」：

1. 文件名主键（去扩展名的 `序号.课名.日期`）在营目录里找候选；
2. 候选大小 > **10 KB**；
3. ffprobe 取时长与课表标称比对，容差 `max(3s, 1%)`（课表 `duration=0` 时只做 1、2）。

- 不用哈希（几百 GB 全读太慢）、不联网查 `Content-Length`（违背「少请求」）；
- 目录扫描一次 `listdir` 建索引再内存匹配，快照带 5 秒 TTL **只作候选来源**，
  命中后一律 `stat` 复核（防刚下完被旧快照漏检）；
- 同主键多文件取最新修改的；旧营目录命中记 `legacy_ok`；
- 时长结果写 sidecar `.xqd_index.json`，跨会话复用。

### 历史与分片缓存

| 项 | 位置 |
|---|---|
| 下载历史 | `~/.xqd_tool/history.json`（`{"version":1,"items":[…]}`，上限 500 条，按成品路径去重） |
| 分片缓存 | `~/.xqd_tool/parts/<md5(绝对成品路径)[:16]>/` |
| 配置 | `~/.xqd_tool/config.json` |
| 凭据 | `~/.xqd_tool/cookie.txt`（环境变量 `XQD_COOKIE` 亦可） |
| 工具点选记录 | `~/.xqd_tool/tools.json` |
| ffmpeg 自装目录 | `~/.xqd_tool/ffmpeg/bin` |

- 启动时 `PurgeOrphanParts` 清掉「已完成」记录对应的残留目录；
  **失败 / 未完成 / 已暂停的保留** —— 那是续传的本钱；
- 成功后才 `PurgeParts` 清该课缓存；失败/中止**必须保留**（写反就废掉续传）；
- 跨会话续传成立的原因：HLS 分片文件名两次会话完全一致（实测 150/150），
  只有 URL 上的签名会变，按文件名落盘即可复用。

### 目录记忆

| 情况 | 顶栏显示 |
|---|---|
| 首次使用 | Windows「下载」Known Folder（读注册表 GUID，用户重定向到别的盘也认） |
| 用户改过 | 一直沿用最后一次（回车或失焦即存） |
| 旧默认 `Z:\太极营` 且本机不存在 | 回落「下载」 |
| 自定目录盘暂时没挂 | 仍记住，不偷改 |

## 八、授权链路（v1.7.1 重点）

兴趣岛 App 是 WebView 壳，登录态在
`/data/data/com.qlchat.xingqudao/app_webview/Default/Cookies`（SQLite，
`value` 列明文存 `userId` / `rsessionId`）。读取方式：

```
MuMuManager sh -v <实例号> -c "sqlite3 <Cookies 路径> \"select host_key,name,value …\"" 
```

走模拟器**内部 RPC + root shell**，不启 adb、不依赖 adb 端口。

### 定位 MuMuManager（七级）

```
tools.json 点选记录 → 环境变量(XQD_MUMU_MANAGER/XQD_MUMU_HOME)
→ 运行中的 MuMu 进程（MainModule.FileName，最可靠）
→ 开始菜单/桌面 .lnk（WScript.Shell 解析 TargetPath）
→ 卸载注册表（DisplayName 含 MuMu 的 InstallLocation / DisplayIcon / UninstallString）
→ 各固定盘目录枚举（名字含 MuMu/Nemu）
→ 限深 2 搜索 → PATH
```

每个候选都「向上回溯 3 层 + 拼相对位置」，兼容 `nx_main\`、`shell\`、
`nx_device\shell\`、根目录直放。找不到就**弹文件选择框**让用户选一次，
写进 `tools.json` 不再问；授权内部报「找不到 MuMuManager.exe」时也会自动弹一次并重试。

### 实例 0~7 全探

- `info -v i` 逐台问，谁在跑记谁；
- 逐台试读 Cookie，先看装没装 App，再挑第一台真有 `userId` + `rsessionId` 的；
- 多台都有登录态时**联网验证**（`QianliaoPlatform.CheckAuthAsync`），取服务端认可的那台；
- 全都验证不了（断网）退回第一台并提示，不把人挡在门外。

### 等待授权窗（`--waitauth` 同源）

失败原因是「App 未登录 / 未检测到登录态 / 没有「兴趣岛」App」时，
不再甩一句报错，而是弹**置顶等待窗**：

- 一行状态 + 日志框 + 倒计时 + 取消；**每 2 秒**扫一遍实例 0~7；
- 没运行实例 → 提示「请先打开 MuMu 模拟器」；有实例就逐台「装没装 App → 能不能读 header」；
- 任一实例读到登录态 → 自动关窗，回主界面重跑一次授权，无需再点；
- 默认 180 秒（`--waitauth 30` 可调），超时给明确文案；同一句错误只播一次。

### 两个开关（底栏右侧）

| 勾选框 | 默认 | 作用 |
|---|---|---|
| 授权时启动模拟器 | 开 | 点「重新授权」时自动拉起 MuMu |
| 授权后关闭模拟器 | 开 | 读到登录态后关闭**本工具自己启动的**模拟器（手动开的不动） |

状态存在 `config.json`（`auto_launch` / `auto_close`）。

## 十、文件命名与产物

```
<下载目录>\<营名>\<序号>.<课名>.<YYYY.MM.DD>.<扩展名>
例：D:\download\太极营\1.《道德经》一至三章.2026.07.27.mp4
```

- **序号** = 营内课表顺序（与 App 里一致）；多营合并不重排；
- **日期** = 该课 `startTime`（本地时区）；
- 只替换 ASCII 非法字符，**全角冒号保留**；遇到 `CON` 等保留名加 `_` 前缀；
- **不产生 `-1`/`-2` 后缀**：重名时正确做法是「已有完整成品→跳过；残件→覆盖重下」；
- 音频课保持原始容器（`.mp3`），不塞进 MP4；实际是 M4A/AAC 的要靠探测判真实格式；
- 封装临时文件为 `<名>.part.mp4`（**必须以 `.mp4` 结尾**，`.part` 结尾 ffmpeg 认不出格式）；
- 同一目录下删除的成品移到 `_已删除\`。

## 十二、已知约束与踩过的坑

| 约束 / 坑 | 说明 |
|---|---|
| ffmpeg 必需 | 分片字节拼接后 `-c copy` 转封装、ffprobe 校验时长；找不到就一键装或指定目录 |
| 禁系统代理 | 业务网关与 CDN 一律 `ProxyHandler({})`，否则代理会返回 HTML |
| 成功码在 `state.code` | 不是顶层 `code` |
| 拼接用 cat 字节拼接 | 不用 ffmpeg concat demuxer（会重置时间戳，实测成品长 6 秒） |
| 分片临时目录逐个删 | 批量删除会触发安全删除钩子阈值（50）被拦，缓存越积越多 |
| `build.cmd` 必须 ASCII + CRLF | LF + 中文注释会让 cmd.exe 按字节错切行，报 `'设置' is not recognized` |
| 表头列宽绑 `$parent[Window]` | 绑 DataContext 会退化成文字自适应，表头与行错位 |
| 缩放热区用整层 `Grid ZIndex=100` | `Panel.ZIndex` 写在 `Border` 上会 `AVLN3000`（无合适 setter） |
| 无边框窗口拖拽 | `TopLevel.PointToScreen` 是 `IRenderRoot` 显式实现，必须强转 |
| 窗口状态事件 | Avalonia `Window` 没有 `WindowStateChanged`，监听 `WindowStateProperty` |
| 附加属性 | `ScrollBarVisibility` 只能用 `ScrollViewer.SetXXX()`，对象初始化器里写不了 |
