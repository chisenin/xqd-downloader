## 一、代码结构

```
xqd.py / _lel/api/qianliao.py   底层采集（ADB / API 网关）
  → xqd_app.py / xqd_api.py      业务动作层
  → xqd_server.py + ui.html      本地 HTTP 服务 + 前端（网页版，仍可用）
  → xqd_gui.py                   ★ PySide6 桌面工具（用户现在用的就是这个）
       ├ xqd_platform.py  平台适配（Platform 基类 + REGISTRY，新平台只写子类）
       ├ xqd_engine.py    下载引擎（解析/分片下载/转封装/进度上报）
       ├ xqd_auth.py      免 adbd 授权（读 MuMu 里的 Cookie）
       ├ xqd_history.py   下载历史 + 分片缓存（跨会话续传）
       └ xqd_dedupe.py    已下载检测 / 残件清理
xqd_pdl.py / xqd_batch.py        并行分片下载 + 全量批处理（CLI）
build_exe.py                     打包单文件 exe
```

- 两套数据源靠 `--mode` 切换：`api`（默认，**不需要模拟器**）/ `adb`（旧路径）。
- API 模式不需要 sweep，播放地址现场解析，`t` 每次都变 → 签名天然新鲜。
- **课名不靠播放反推** —— 课表在列表页/接口里一次拿全。

## 三、学无止下载器的关系（合规声明）

★ 本项目**确实用了学无止下载器的部分材料**（只在 `_lel/` 下，运行时主链路完全自建）：

| 材料 | 位置 | 用途 |
|---|---|---|
| `netease_mooc.py` | `_lel/core/` | 独立复现其 163 解密内核 |
| app.asar 明文 JS | `_lel/login/` | 登录流程参考 |
| PYZ 破解脚本 | `_lel/v2/` | 提取 app.asar 资源 |
| 提取脚本 | `archive/xwz-v2/` | 打包辅助 |

★ **官方仓库 = `github.com/Xue-Wu-Zhi/xuewuzhi-downloader`**（MIT、24★）。
它的 NOTICE 明确：**官方客户端不在 MIT 授权范围内**（核心引擎不在仓库里）
→ 我们复现的 163 内核**不能声称 MIT**。
旧地址 `github.com/PyJun/Mooc_Downloader`（中文教程常引）**已 404**，不要引用。

「关于」对话框 + 仓库根 `NOTICE.md` 都列了：
学无止(MIT) / PySide6(LGPL-3.0) / FFmpeg(LGPL|GPL) / pycryptodome(BSD-2|Public Domain)。
分析细节见 `docs/07-学无止V2.19.70分析.md`。
