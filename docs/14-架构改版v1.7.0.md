# v1.7.0 架构改版：Avalonia 取代 WPF，换机器能直接跑

> 起因：用户反馈「这个项目和上一个项目（hgvd-downloader）一样，换机器后无法运行」。
> 结论：发行方式与源码里的本机硬编码路径是病根，跟界面框架无关 —— 但界面框架顺手换掉，
> 因为 WPF 做不出自包含单文件、也只能跑 Windows。

## 一、诊断出的四个根因

| # | 根因 | 证据 |
|---|---|---|
| 1 | 发行包是 **framework-dependent 目录 zip** + `gui/启动.bat` | 新机器没装 .NET 8 桌面运行时，双击就报错退出 |
| 2 | 源码里**硬编码作者本机路径** | `D:\Program Files\Netease\MuMu`、`ffmpeg-8.0.1...\bin`、`adb.exe`、固定设备 `192.168.1.101:5555`、`C:\Users\<user>\Downloads` |
| 3 | WPF 天生绑 Windows，且**不能自包含单文件** | 运行时依赖系统，换机器即碎 |
| 4 | Python 版 v1.6.1 已从仓库删除，**改一行逻辑必须先过 C# 编译** | 迭代成本高，试想法不划算 |

远程分支 `csharp-wpf`。

## 三、去本机化：唯一入口 `Setup/ToolLocator.cs`

所有「外部程序在哪」的问题都收敛到这一个类，别处不许再写死路径。

| 工具 | 查找顺序 |
|---|---|
| ffmpeg / ffprobe | `~/.xqd_tool/ffmpeg/bin`（自装目录）→ `tools.json` 点选记录 → `XQD_FFMPEG_DIR` → PATH |
| MuMuManager | `tools.json` 点选记录 → `XQD_MUMU_MANAGER` → `XQD_MUMU_HOME` → Program Files / Program Files (x86) / ProgramW6432 / LOCALAPPDATA 常见目录 → **各固定盘 `Netease\MuMu*`** → 限深 2 搜索 → PATH |
| adb | 点选记录 → `XQD_ADB` → MuMu 同级 `adb.exe` → PATH |
| 设备 | `XQD_ADB_DEVICE` → 否则 `adb devices` 取第一台在线设备 |

★ 实测教训：MuMu 12 的默认安装目录是 **`Netease\MuMuPlayer-12.0`**，
早期候选列表只有 `Netease\MuMu`，于是「机器上明明装了」也被判成未安装
（本机就是这种：`D:\Program Files\Netease\MuMuPlayer-12.0`）。现已补全带版本号后缀的目录名。

下载目录不再写 `C:\Users\<用户名>\Downloads`，改为读注册表
`User Shell Folders` 的「下载」Known Folder（本机已被用户重定向到 `D:\download`），
读不到才回落 `%USERPROFILE%\Downloads`。

## 四、界面（Avalonia）

功能与 WPF 版对齐：

- **单表 8 列**：状态胶囊 / 课程（自适应宽度）/ 所属营 / 时长 / 大小 / 速度 / 剩余 / 进度；
- **无边框窗口** + 自绘最小化/最大化/关闭 + 8 个缩放热区 + 顶栏可拖；
- 左侧营列表（分组小标题、同名营加序号、三态全选），勾选即把课表并入右侧同一张表；
- 5 个视图切换（全部/待下载/下载中/已完成/失败）+ 画质下拉 + 重新扫描 / 重置记录；
- 暂停 / 继续 / 取消 / 开始下载；最多 3 路并发；右键：下载 / 重试 / 复制课名 / 打开文件夹 / 删成品；
- 历史（含残件清理）、汇总条、日志区、状态栏版本号；Ctrl+Q 退出；
- 关于窗（版本/运行时/配置目录/下载目录/快捷键）、环境检查窗（依赖状态 + 一键装 ffmpeg + 指定 MuMuManager）。

Viewport 细节：Avalonia 的 `TopLevel.PointToScreen` 是 `IRenderRoot` 的
**显式接口实现**，直接调用会编译报「名称不存在」，必须
`((IRenderRoot)this).PointToScreen(p)`。

## 五、出版本

```bash
cd xqd-avalonia
./build.cmd             # 或 ./build.sh
# → dist/xqd-downloader-v1.7.0.exe（约 44 MB，自包含单文件）
```

目标机器：Windows 10/11 x64，**不需要 .NET、不需要 Python**。

发版流程：`git tag v1.7.0 && git push origin master v1.7.0` →
Actions 跑回归 → 构建 exe → 核对 FileVersion 与标签 → 建 Release 并上传。
