**教训（写死，别再犯）**：
- ★ **`robocopy /MIR` 是「把目标目录清空成源目录」** —— 极度危险，
  只在**专门的空目录**上用，绝对不要指向工作区/仓库目录。
  要删单个文件，老老实实用 `rm` / `del`。
- ★ **Windows 保留设备名（NUL / CON / AUX / PRN / COM1…）**：
  `rm`、`del`、`DeleteFileW`（含 `\\?\` 前缀）、robocopy 全部无效 ——
  DOS 路径语义下它们指向设备。要删只能：
  ① 重命名后再删；② 在 Git Bash 里用 `rm`（MSYS 层能绕过）；
  ③ 用 `\\?\` + 完整 NT 路径 `\??\D:/.../NUL` 调 `NtDeleteFile`。
  本次的 `NUL` 是 `ssh-keyscan github.com > NUL` 在 Windows 上误建的
  （`> NUL` 变成了文件名而不是丢弃输出）—— 内容是**公钥**，无害。
- ★ **项目记忆不在 git 里**（`.workbuddy/` 被 gitignore），
